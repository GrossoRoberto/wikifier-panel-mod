# Contributing

Thanks for your interest in wikifier-panel-mod.

**For now this project accepts bug reports and suggestions only, through [Issues](../../issues).** Pull requests are not accepted at the moment: a pull request opened without a prior discussion may be closed without review.

## Reporting a bug

Open an issue with the "Bug report" form. Please include:

- the wiki-tree version (`claude plugin list`),
- where you run Claude Code (Desktop, Windows Terminal, classic Windows console, macOS / Linux),
- the `language` set in your `infowiki.md`,
- what you did, what you expected and what happened, with a screenshot if you can.

Remove anything private from screenshots and pasted output.

## Suggesting an improvement

Open an issue with the "Suggestion" form. Describe the idea and the problem it solves.

## Known limitation

In the classic Windows console the buttons show squares instead of the padding character. This is documented in the README; you do not need to report it again.
